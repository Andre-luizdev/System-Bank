Olá! Este é um dos meus projetos de estudo em Java. 

O objetivo foi criar um sistema de banco que roda pelo terminal (console), focado em praticar como os objetos interagem entre si e como tratar erros que podem acontecer em um sistema real.

O que o sistema faz:
Criar Conta: Dá para cadastrar novos clientes.

Fazer Login: Você entra na conta usando o número dela para realizar as operações.

Operações Bancárias:

Depósito: Para colocar dinheiro na conta.

Saque: O sistema verifica se você tem saldo e se não passou do seu limite.

Transferência: Consegui implementar a lógica para enviar dinheiro de uma conta para outra, verificando se a conta de destino realmente existe.

Avisos de Erro: Se o usuário tentar sacar mais do que tem ou usar um número de conta errado, o sistema exibe uma mensagem em vez de "quebrar" (usando o try-catch).
